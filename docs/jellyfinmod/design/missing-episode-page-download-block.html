The page

Upstream's episode page, with the mod's additions in the two places upstream leaves empty for an episode without a file: the track-selector slot holds the download block, and the header's button row holds Get a Release and More (as built). Everything else is upstream's layout: the still (no disc on it — the block says it; user, 2026-10-13), the name, the misc line, overview, details lines, Cast & Crew, Guest Stars.
