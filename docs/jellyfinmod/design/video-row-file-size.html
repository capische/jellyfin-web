Video row and file size

Upstream's track block on a detail page with the mod's file chooser in the Video row. The Video value shows only video facts; the audio facts live in the Audio row; the size goes where the toggle says.

Needs several tracks; one track is a non-opening field.

The track block

Rules

Video row, closed: resolution word (600) · video marks (codec, bit depth, HDR) · size at the right end in the secondary colour, just before the chevron. No audio there.
Audio row: a dropdown drawn like the Video one. Closed: language (600) · audio marks (DTS-HD MA, Atmos, TrueHD, DD+, AAC; the channel layout 7.1 / 5.1 / 2.0) · Default / Forced / Commentary as muted text. Open: one row per track, drawn the same way, the current one with the blue bar. A file with ONE track shows the same field without a chevron, not clickable, so the block keeps its shape and the track's facts stay readable.
Subtitles row: the same dropdown: "Off", then each subtitle as language (600) · format mark (SRT, PGS, ASS) · Default / Forced muted. The three rows then share one trigger, one list and one mark style.
Open Video list: each file is one row: resolution · video marks │ audio marks (muted, smaller, because they tell two files apart) · extras (episode range, "removes 3 Nov") … size right-aligned at the row's end, then the row's icons. The selected row and the closed trigger therefore read the same left to right, with the size in the same place.
Phone: the row's audio and size drop to a second line; the trigger keeps the size at its right end (it truncates the marks first, never the size).
TV: same at 125 %; the trigger and each row are focus stops; nothing changes.
