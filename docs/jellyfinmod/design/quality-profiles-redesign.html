The Quality Profiles section

The section card as it is today, with two changes: each row says in one plain line what the profile does (instead of its 24-name list), and preset profiles carry a Preset chip. Add Profile is the section's blue action; Add Predefined Profiles is grey and appears only while a preset is missing. The default is chosen with the star icon on a row (as today) and shown as the blue Default chip; the Grabbing section's "Default quality profile" select stays as the second place to set it.

Add / Edit dialog

Simple by default: a starting point, a name, the best quality wanted, whether to fall back, a three-way file size, whether to upgrade later — and a live sentence saying what the profile will pick. Advanced holds the whole model: a source × resolution matrix instead of the 24-line list, the order tried with Move Up / Move Down icons, the cutoff, the upgrade mode, the minimum score and seeders, and the size limits as numbers. Changing a simple control rebuilds the advanced values; editing the advanced values marks the profile Custom. The server's two rules are checked live: at least one quality, and a cutoff that is one of them.
